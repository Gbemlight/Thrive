# Thrive Tribe — Landing

This project is a Tailwind + React + Vite landing page for Thrive Tribe.

Quick start:

```bash
npm install
npm run dev
# open http://localhost:5174
```

Build for production:

```bash
npm run build
npm run preview
```

Structure:
- `src/components` — reusable sections and UI
- `src/pages` — route-level pages (home + placeholders)
- Tailwind is configured in `tailwind.config.cjs`

If you want a design pass (colors, motion, editorial tone), tell me which areas to refine next.
